RaceCircuit · Reusable Component · v0.1.0

One component. Many circuits.

A self-contained race-circuit widget. Drop it in anywhere — story pages, self-assessment tools, sales decks, dashboards. Configure the turns, the cars, and the positions; the component handles SVG path-following, autoplay, content panels, accessibility, and reduced-motion.

Demo 1 — Brenden's Story (the baked-in story)

Pass RaceCircuit.brendenTurns and RaceCircuit.brendenPositions and you get the canonical 8-turn pit-crew narrative for free. Identical behavior to the standalone Pit Crew direction piece, in 12 lines of init code.

RaceCircuit.create('#circuit-story', {
  turns:        RaceCircuit.brendenTurns,
  lapPositions: RaceCircuit.brendenPositions,
  competitors: [
    { color: '#8F95A0', glow: 'rgba(143,149,160,0.35)' },
    { color: '#E78635', glow: 'rgba(231,134,53,0.40)' }
  ],
  autoplay: true,
  autoplayMs: 5000
});

Demo 2 — Self-Assessment Tool

Same component. Different configuration. Story panels hidden, controls hidden, autoplay off. The user's car moves only when they answer a question. Competitor cars represent industry-average positions and stay slightly ahead until the user crosses them.

Awaiting first answer…
var assess = RaceCircuit.create('#circuit-assess', {
  turns: ASSESSMENT_TURNS,        // your custom content per stage
  lapPositions: ASSESSMENT_POSITIONS,
  competitors: [{ color: '#8F95A0' }, { color: '#E78635' }],
  autoplay: false,                // user-driven, not auto
  showControls: false,
  showLapDisplay: false,          // no story panels — just the visualization
  startTurn: 1,
  progressLabel: 'STAGE',
  onTurnChange: function (turn) {
    // Update your assessment UI based on user's current stage
    quizState.textContent = 'You\'re at Stage ' + turn + ' / 8';
  }
});

// Wire up to the assessment's answer buttons:
btn.addEventListener('click', function () {
  var turn = parseInt(btn.dataset.turn, 10);
  assess.goTo(turn);
});
