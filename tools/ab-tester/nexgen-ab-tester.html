HOW THE TESTER WORKS
The A/B logic

Both versions receive the exact same prospect profile. The only difference is what gets added to the AI system context:

Version A — Baseline

Prospect profile + NexGen positioning strategy only. No tribal knowledge. This is what the tool produces on day one, before any team input.

Version B — Enriched

Same profile + same strategy + everything in your knowledge base. As KB entries grow, B gets sharper, more specific, more human-sounding, and more persuasive.

How scoring works

After both proposals generate, a third AI call evaluates them across 5 dimensions:

Specificity
Does it use the prospect's real language and situation?
Proof points
Are there real numbers and concrete evidence?
Credibility
Does it sound like someone who has been in their building?
Persuasiveness
Would this prospect feel compelled to take the next step?
Personalization
Is the proposal unique to this person, or generic?
Recommended testing workflow
1
Run a test with an empty knowledge base. This is your baseline. Note the scores — especially Specificity and Proof Points which are typically lowest at zero.
2
Add 3–5 knowledge entries (use the quick-add presets to start). Focus on client insights, objection responses, and ROI data points.
3
Run the same profile again. Compare the side-by-side output and the improvement delta. The scoring panel shows exactly which dimensions improved.
4
Try different prospect profiles to see how the enrichment lands differently for an EPLAN rep vs. a shop owner vs. an OEM.
5
When Version B consistently scores 20%+ higher, you are ready to export the KB and load it into the production tools.
